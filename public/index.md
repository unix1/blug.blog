[blug](https://github.com/unix1/blug) is a simple and small static blog and site generator. Set up and run your site on Cloudflare in minutes.

Quick how it works

1. Run `blug init` to create a starter site.
2. Write content, customize styles and templates any way you like.
3. Run `blug generate` and `blug serve` to write HTML and preview locally.
4. Run `blug deploy` to push your site to Cloudflare.

See [README.md](https://github.com/unix1/blug/blob/main/README.md) for more info. Example? This site! See the [blug.blog repo](https://github.com/unix1/blug.blog).
