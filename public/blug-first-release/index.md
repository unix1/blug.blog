[blug](https://github.com/unix1/blug) is a small static blog generator. Posts live as markdown folders under `public/`. One Node script turns them into HTML. Preview with `serve`. Deploy with rclone to S3-compatible storage such as Cloudflare R2.

This site is the first dogfood. [blug.blog](https://blug.blog) is generated by blug and hosted the same way a new site from the template would be. The original hello-world post is still here.
