blug is a small and simple static blog generator. Here's how you use it.

Create a new blog post

  • create a folder inside public, e.g. public/my-first-blog-post and write your content in index.md with markdown.
  • add images or any media in the same folder and link or embed with relative paths.

Preview content

  • Run npm run generate to create your blog site locally on your computer.
  • Run npm run dev to create a local web server, then visit the URL it outputs, (most likely http://localhost:3000).

Publish changes

  • run npm run deploy to publish all changes to your live blog.

Or better yet, have your agent do it all for you!

blug supports any S3 compatible storage. It has been tested on Cloudflare R2.

This site blug.blog itself is generated by blug and hosted the same way a new site from the template would be. The original hello world post is still here too.

For more info and setup details, see blug project on GitHub.
